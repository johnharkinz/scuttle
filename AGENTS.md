# Scuttle

Scuttle is a JavaScript rendering gap analyser. It compares what the server sends with what JavaScript reveals. Nothing more.

Also read the Camas workspace `AGENTS.md` (one level up). `camas-design` is the design source of truth for any visual or UI work.

## Keep it narrow

Fewer trustworthy findings beat a sophisticated report full of false positives. Before adding a feature or abstraction beyond the current milestone, flag it and get agreement.

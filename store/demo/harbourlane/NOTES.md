# harbourlane

**Role:** none. This is a made-up demo for the store screenshot (`npm run store-assets`), not a fixture.
**URL:** https://harbourlane.example/

A made-up bakery's home page, written by hand so that no real company's site appears in the store listings. It is a client-rendered shell: the server sends a placeholder title and description and an empty `#root`, and JavaScript fills in the rest. It's the same page as the report capture on camas.dev/scuttle/.

Nothing was captured. The values below are made up for the report's capture conditions, in the order the extension works: the capture with JavaScript first, then the fetch straight afterwards.
